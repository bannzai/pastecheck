PasteCheck

Check for secrets
before you paste

If the text or image you copy contains strings that look like API keys, tokens, private keys, or card numbers, PasteCheck warns you from the menu bar. You can notice before you paste them into an AI chat or Slack. Inspection happens inside your Mac, and clipboard contents are not sent anywhere.

Inspected inside your Mac the moment you copy

Watches your copies and warns

Every time the clipboard changes, it inspects the contents and notifies you if there is a string that looks like sensitive information. It does not get in the way of pasting.

Detects common secret formats

It recognizes access keys for AWS, GitHub, OpenAI, Slack, and more, as well as JWTs, PEM private keys, and credit card numbers, by their format.

Text inside images too

When you copy a screenshot, it reads the text in the image inside your Mac and runs the same checks.

Sends nothing anywhere

There are no servers and no accounts. Clipboard contents are not written to files or the network, and the detected value itself is never shown on screen.

Made for moments like these

  • You copied a whole terminal output to paste into an AI chat, and a token from an environment variable was mixed in
  • You were sharing part of a configuration file on Slack, and the private key line was selected too
  • An access key showed up in a screenshot of an error screen
