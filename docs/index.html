秘密が混じっていないかを確認

コピーしたテキストや画像に API キー・トークン・秘密鍵・カード番号らしき文字列が混じっていたら、PasteCheck がメニューバーから警告します。AI チャットや Slack に貼ってしまう前に気づけます。検査は Mac の中で完結し、クリップボードの内容はどこにも送られません。

コピーした瞬間に Mac の中で検査

コピーを監視して警告

クリップボードが変わるたびに内容を検査し、機密情報らしき文字列があれば通知で知らせます。貼り付けの操作は妨げません。

よくある秘密の形式を検出

AWS・GitHub・OpenAI・Slack などのアクセスキー、JWT、PEM 形式の秘密鍵、クレジットカード番号を形式から判定します。

画像の中の文字も

スクリーンショットをコピーした時は、画像の中の文字を Mac の中で読み取って同じ検査を行います。

どこにも送らない

サーバーもアカウントもありません。クリップボードの内容はファイルにもネットワークにも書き出されず、検出した値そのものは画面にも出しません。

こんな場面のために

  • ターミナルの出力をまるごとコピーして AI チャットに貼る時に、環境変数のトークンが混じっていた
  • 設定ファイルの一部を Slack で共有する時に、秘密鍵の行まで選択していた
  • エラー画面のスクリーンショットに、アクセスキーが写り込んでいた
