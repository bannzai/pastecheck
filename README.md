# PasteCheck

PasteCheck is a macOS menu bar app that warns you before you paste when the text or image you copied to the clipboard looks like it contains sensitive data, such as API keys, access tokens, private keys, or credit card numbers. It is designed to only warn without rewriting the clipboard, and to do all inspection on your Mac without sending clipboard contents anywhere. See https://bannzai.github.io/pastecheck/ for an overview.

## Status

PasteCheck is in development and has not been released yet. The requirements are in `documents/PROJECT.md`.
